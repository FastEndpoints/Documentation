# Operations

## Deploy model
Static site generated by `npm run build` into `docs/`. The README links a Cloudflare Pages preview host; deployment automation is not defined in this repository. Hosting changes need external configuration verification.

| Environment | URL (documented) |
| --- | --- |
| Production | `https://fast-endpoints.com` |
| Dev preview | `https://dev.fastendpoints-doc-site.pages.dev` |
| Alternate Pages URL in config | `https://fastendpoints-doc-site.pages.dev` |

`src/config.ts` currently hardcodes `isProduction = true`, so `siteUrl` and related SEO fields use the production host even when building non-prod unless that flag is changed.

## Build-time network access
Homepage prerender fetches contributors from GitHub for the framework and docs repositories. Non-OK HTTP responses return an empty list. Network errors and JSON parsing errors are not caught by the helper or homepage loader, so offline builds can fail. Do not assume contributor loading always fails soft.

## Config
Site configuration lives in `src/config.ts`, not env files. Its Algolia fields do not drive in-app search, which uses FlexSearch + `/search.json`.

## Caveats
- `/docs` output directory is gitignored; publish pipeline must build before deploy.
- Sitemap URLs use `config.siteUrl`; wrong production flag skews absolute URLs.
